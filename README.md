# frauddetection

Uses AdaBoost algorithm to create a machine learning model for detecting fraudulent credit card transactions.
To use, run 
'''
java-algs4 BoostingAlgorithm princeton_training.txt princeton_test.txt 5 80
'''
Alternative options for the training and test datasets include:
small_training.txt
large_training.txt
small_test.txt
large_test.txt

Completed for COS226 (Data Structures and Algorithms) https://www.cs.princeton.edu/courses/archive/spring26/cos226/assignments/fraud/specification.php
